# Unregistered User Stories
As an Unregistered User, I want to complete a personalized health questionnaire before signing up and view an AI-generated pacing blueprint, so that I understand my baseline and see the value of the platform before creating an account.
As an Unregistered User, I want to register an account, so that I can access the platform's features.
As an Unregistered User, I want to view the app's features, so that I can understand the platform's functionality before registering.
As an Unregistered User, I want to view public feedback, so that I can understand other users' experiences with the platform.
As an Unregistered User, I want to view available subscription tiers and pricing, so that I can compare free and premium benefits before signing up.
As an Unregistered User, I want to view the platform's privacy policy and non-clinical disclaimer, so that I understand how my health data is protected under the PDPA before registering.

# Registered User Stories
As a Registered User, I want to log in to my account, so that I can access my personalised health and lifestyle features on the platform.
As a Registered User, I want to log out of my account, so that I can protect my account from unauthorized access.
As a Registered User, I want to view my profile, so that I can check my personal information.
As a Registered User, I want to change my password, so that I can maintain my account security.
As a Registered User, I want to reset my password via email, so that I can regain access if I forget my login credentials.
As a Registered User, I want to edit my profile display name, so that I can personalize how my name appears on the platform.
As a Registered User, I want to complete an onboarding flow with my lifestyle baseline and PDPA consent, so that the platform can provide personalized recommendations from the start.
As a Registered User, I want to submit feedback and trust ratings on AI recommendations, so that I can help improve the platform's guidance and share public reviews.
As a Registered User, I want to log whether I completed or skipped a daily recommendation, so that I can track my adherence to suggested routines.
As a Registered User, I want to view my 7-day and 30-day habit and biometric trends, so that I can monitor my consistency and progress over time.
As a Registered User, I want to discover and reserve marketplace services and events, so that I can find fitness offerings that match my interests.
As a Registered User, I want to participate in step challenges, so that I can stay motivated and engage with the community.
As a Registered User, I want to input my health data, so that the platform can provide recommendations relevant to my needs.
As a Registered User, I want to log my daily activities and habits, so that I can track my lifestyle patterns.
As a Registered User, I want to synchronise my wearable device data or import activity logs, so that my activity information can be updated automatically.
As a Registered User, I want to create fitness goals, so that I can work towards my personal fitness targets.
As a Registered User, I want to update my fitness goals, so that they reflect my changing needs.
As a Registered User, I want to delete fitness goals, so that I can remove goals that are no longer relevant.
As a Registered User, I want to set my workout preferences, so that I receive suitable workout recommendations.
As a Registered User, I want to specify my available time, so that recommended activities fit my schedule.
As a Registered User, I want to set my dietary preferences, so that meal recommendations account for my food preferences and restrictions.
As a Registered User, I want to view lifestyle recommendations, so that I can identify ways to improve my daily habits.
As a Registered User, I want to understand why a recommendation was generated via explainable AI factors, so that I can make informed decisions about whether to follow it.
As a Registered User, I want to compare recommendations from different What-If scenarios, so that I can identify options that better suit my circumstances.
As a Registered User, I want to subscribe to a premium plan, so that I can unlock personalized workout and meal plans and advanced AI insights.
As a Registered User, I want to withdraw my data sharing consent from challenges or cohorts, so that I maintain control over my personal data under PDPA regulations.

# Premium User Stories
# Note: Premium Users inherit all Registered User capabilities in addition to the following:
As a Premium User, I want to generate a personalized workout plan, so that I can follow a structured plan based on my fitness goals and preferences.
As a Premium User, I want to generate a personalized meal plan, so that I can explore meal suggestions suited to my dietary preferences.
As a Premium User, I want to view and refer back to my saved workout and meal plans, so that I can follow them throughout the week.
As a Premium User, I want to view detailed explanations of my recommendations, so that I can better understand how the AI generates its suggestions.
As a Premium User, I want to explore more What-If scenarios, so that I can compare recommendations under different lifestyle circumstances.
As a Premium User, I want to compare multiple personalized recommendations, so that I can select options that best suit my needs.
As a Premium User, I want to receive suggestions for adjusting my goals based on my progress, so that I can maintain realistic and relevant targets.
As a Premium User, I want to access additional expert-reviewed educational content, so that I can learn more about health and lifestyle topics.
As a Premium User, I want to view my subscription details, so that I can check my plan and renewal information.
As a Premium User, I want to cancel my subscription renewal, so that I can stop future renewals according to the subscription terms.
As a Premium User, I want to renew my subscription, so that I can continue accessing premium features.

# Business User Stories
As a Business User, I want to register a business account, so that I can set up my organization's presence on the platform.
As a Business User, I want to log in securely with my credentials, so that I can access my business portal and management tools.
As a Business User, I want to reset my password using my registered email, so that I can regain access if I forget my login details.
As a Business User, I want to log out of my session, so that my business account remains secure on shared or unattended devices.
As a Business User, I want to view and update my business profile details, so that users see accurate information about my brand or coaching service.
As a Business User, I want to publish new fitness offerings such as training sessions, memberships, or group classes, so that platform members can easily discover and reserve them.
As a Business User, I want to edit existing service details, so that my pricing, timings, and class descriptions remain accurate.
As a Business User, I want to delete a service that is no longer offered, so that users cannot view or sign up for discontinued offerings.
As a Business User, I want to view a list of all events I have created, so that I can track upcoming schedules and manage them easily.
As a Business User, I want to create a new fitness event, workshop, or product showcase, so that users can register and attend.
As a Business User, I want to update event information, so that registered attendees are informed of any changes to time, venue, or details.
As a Business User, I want to delete or cancel an event, so that users know the event will no longer take place.
As a Business User, I want to view the list of registered participants for my events, so that I can track attendance and capacity.
As a Business User, I want to create and publish posts with tips, promotions, or announcements, so that I can engage directly with platform users.
As a Business User, I want to delete outdated or expired posts, so that my business feed stays clean and relevant.
As a Business User, I want to set up a leaderboard challenge, so that I can motivate users and promote brand engagement.
As a Business User, I want to view the current leaderboard standings, so that I can see top performers.
As a Business User, I want to view user performance stats and activity trends, so that I can assess overall client progress, health improvements, or program effectiveness.

# System Admin Stories
As a System Admin, I want to log in to the admin account, so that I can access administrative functions.
As a System Admin, I want to log out of the admin account, so that I can protect the system from unauthorized access.
As a System Admin, I want to reset my password, so that I can regain access if I forget my login credentials.
As a System Admin, I want to view and search user accounts, so that I can locate specific users when necessary.
As a System Admin, I want to view user account details, so that I can review account information when handling issues.
As a System Admin, I want to activate, suspend, or deactivate user accounts, so that I can enforce platform policies and handle problematic accounts.
As a System Admin, I want to view user feedback and recommendation trust ratings, so that I can identify issues and areas for improvement.
As a System Admin, I want to approve or hide user feedback from the public landing page, so that only appropriate reviews are displayed to visitors.
As a System Admin, I want to approve or reject expert content, so that only suitable content is published on the platform.
As a System Admin, I want to manage subscription plan details, so that users can view the correct pricing and benefits.
As a System Admin, I want to audit algorithmic fairness across demographic subgroups, so that I can verify AI recommendations remain unbiased.
As a System Admin, I want to view system error and audit logs, so that I can investigate and resolve technical problems.
